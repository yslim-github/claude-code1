# 캐릭터 디자인 가이드

## 주요 캐릭터 (5명)

### 1. 박상무 (50대 남성)

**외모**:
- 나이: 50대 중반
- 체형: 약간 배가 나온 중년 체형
- 헤어: 짧은 검은 머리, 옆머리 약간 흰머리
- 안경: 검은 테 안경 (선택)
- 의상: 네이비 정장, 흰 와이셔츠, 파란색 넥타이

**표정**:
- 초반: 거만한 표정, 턱을 치켜든 모습, 팔짱 낀 포즈
- 중반: 땀 흘리는 모습, 당황한 표정, 눈 크게 뜬 모습
- 후반: 겸손한 미소, 부드러운 눈빛, 감사하는 표정

**자세**:
- 초반: 가슴 펴고 거만한 자세
- 중반: 구부정한 자세, 머리 감싸는 모습
- 후반: 자연스럽고 편안한 자세

**AI 이미지 생성 프롬프트 (Midjourney/DALL-E)**:
```
Korean businessman in his 50s, slightly overweight, short black hair with some gray,
navy suit, white shirt, blue tie, arrogant expression, arms crossed,
office background, webtoon style, clean lines, Korean manhwa art style,
professional lighting, front view
```

### 2. 제니 (28세 여성)

**외모**:
- 나이: 20대 후반
- 체형: 날씬한 체형
- 헤어: 어깨까지 오는 갈색 머리, 단정한 스타일
- 의상: 베이지 블라우스, 검은색 슬랙스, 또는 회색 재킷

**표정**:
- 초반: 실망한 표정, 한숨 쉬는 모습
- 중반: 진지하고 집중하는 표정
- 후반: 자신감 있는 미소, 밝은 표정

**자세**:
- 초반: 주저앉은 자세, 고개 숙인 모습
- 중반: 노트북 앞에서 작업하는 모습
- 후반: 당당하게 발표하는 자세

**AI 이미지 생성 프롬프트**:
```
Korean businesswoman in her late 20s, slim build, shoulder-length brown hair,
beige blouse, black pants, confident expression, working on laptop,
office setting, webtoon style, Korean manhwa art, clean illustration,
professional and capable look
```

## 감정 표현 가이드

### 박상무 감정 변화
1. **거만함** (장면 1-4): 턱 치켜듦, 팔짱, 큰 제스처
2. **당황** (장면 5-6): 땀방울, 큰 눈, 떨리는 손
3. **패닉** (장면 7-11): 얼굴 창백, 머리 감싸기, 절망적 표정
4. **감사** (장면 12-13): 눈물 글썽, 진심 어린 표정
5. **겸손** (장면 14-17): 부드러운 미소, 자연스러운 자세

### 제니 감정 변화
1. **무시당함** (장면 1-2): 실망, 한숨
2. **걱정** (장면 3-4): 진지한 표정
3. **해결사** (장면 11-12): 자신감, 결단력
4. **성취** (장면 14-17): 밝은 미소, 자랑스러움

## 이미지 생성 워크플로우

### 1단계: 캐릭터 기본 이미지 생성
각 캐릭터당 3-5개 버전:
- 정면
- 측면
- 다양한 감정 (기쁨, 슬픔, 놀람, 화남, 당황)

### 2단계: 장면별 배경 생성
- 회의실 (3-4 앵글)
- 사무실 (2-3 앵글)
- 개인 사무실 (2 앵글)
- 복도 (1-2 앵글)
- 식당 (1 앵글)

### 3단계: 합성 장면 생성
캐릭터 + 배경 조합으로 각 장면 완성
