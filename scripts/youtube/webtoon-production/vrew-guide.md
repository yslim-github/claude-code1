# VREW 사용 가이드

웹툰 스타일 영상 제작을 위한 VREW 완전 가이드입니다.

---

## VREW란?

**VREW**(브루)는 AI 음성과 자동 자막을 지원하는 영상 편집 프로그램입니다.

### 다운로드
- 공식 사이트: https://vrew.voyagerx.com/ko/
- Windows, Mac 지원
- **무료 버전** 사용 가능 (제한적)

---

## 준비물

### 필수
1. ✅ VREW 프로그램 설치
2. ✅ 장면별 이미지 파일 (50-70개)
3. ✅ 장면별 스크립트 파일 (17개)

### 선택
1. 🎵 BGM 파일 (무료: YouTube Audio Library, Artlist)
2. 🔊 효과음 파일 (Freesound.org)

---

## 제작 프로세스

### 1단계: 새 프로젝트 만들기

```
1. VREW 실행
2. "새로 만들기" 클릭
3. "텍스트로 영상 만들기" 선택
4. 16:9 비율 선택 (YouTube용)
```

---

### 2단계: 스크립트 입력

#### 방법 A: 한 번에 입력 (빠름)

```
1. 전체 대본 복사
2. VREW에 붙여넣기
3. "화자 구분" 선택
4. 캐릭터별로 자동 분리
```

**화자 설정**:
```
박상무: [남성 중년 목소리]
제니: [여성 젊은 목소리]
마이크: [남성 젊은 목소리]
수잔: [여성 중년 목소리]
김인턴: [남성 젊은 목소리 - 밝은 톤]
내레이터: [중성적 목소리]
```

#### 방법 B: 장면별 입력 (권장)

```
장면 1 입력 → 이미지 삽입 → 검토
장면 2 입력 → 이미지 삽입 → 검토
...
```

- 속도: 0.9x (약간 느리게)

**제니**:
- "한국어-여성-지영" (명랑한 목소리)
- 속도: 1.0x
- 피치: +1

**마이크**:
- "한국어-남성-현우" (친절한 목소리)
- 속도: 1.0x
- 피치: 기본

**수잔**:
- "한국어-여성-수진" (차분한 목소리)
- 속도: 0.95x
- 피치: -1

**김인턴**:
- "한국어-남성-민수" (발랄한 목소리)

- 피치: +2

**내레이터**:
- "한국어-남성-서준" (중성적)

#### 음성 적용 방법
```
1. 텍스트 선택
2. 우측 "음성" 탭
3. 화자 선택
4. "적용" 클릭
5. 미리듣기로 확인
```

---

### 4단계: 이미지 삽입

#### 방법 A: 자동 삽입
```
1. 타임라인에서 구간 선택
2. "미디어 추가" → "이미지"
3. 해당 장면 이미지 선택
4. 지속 시간 자동 조정
```

#### 방법 B: 수동 조정 (권장)
```
1. 각 대사 구간마다 이미지 삽입
2. 이미지 지속 시간 = 대사 시간 + 0.5초
3. 장면 전환 시 "페이드" 효과 추가
```

#### 이미지 배치 예시

**장면 1 - 회의실**
```
00:00 - 00:15: 회의실 전경 (박상무 중앙)
00:15 - 00:25: 박상무 클로즈업 (거만한 표정)
00:25 - 00:30: 제니 반응샷 (실망한 표정)
00:30 - 00:45: 회의실 전경 (전체)
```

---

### 5단계: 자막 설정

#### 자동 자막
```
1. "자막" 탭 클릭
2. "자동 생성" 선택
3. 스타일 선택:
   - 폰트: 나눔고딕 Bold
   - 크기: 40-50
   - 색상: 흰색
   - 테두리: 검은색 (두께 3)
   - 위치: 하단 중앙
```

#### 감정 표현 자막 (선택)
```
(땀 흘리며): [기울임체, 회색]
(큰 소리로): [빨간색, 크기 +5]
(작은 목소리로): [회색, 크기 -5]
(한숨): [이탤릭, 연한 회색]
```

---

### 6단계: BGM 및 효과음

#### BGM 추가
```
1. "오디오" 탭
2. "배경음악 추가"
3. 볼륨 조절: 20-30% (대사가 중요)
```

#### BGM 구간 설정

**1막 (0:00-8:00)**: 경쾌한 오피스 음악
- 추천: "Corporate Success" (YouTube Audio Library)

**2막 (8:00-18:00)**: 긴장감 있는 음악
- 추천: "Tension" (YouTube Audio Library)

**3막 (18:00-끝)**: 따뜻하고 감동적인 음악
- 추천: "Inspiring" (YouTube Audio Library)

#### 효과음 (선택)
```
- 컴퓨터 오류음: 비밀번호 틀릴 때
- 전화벨: 전화 장면
- 문 두드리는 소리: 앤더슨 등장
- 박수 소리: 프레젠테이션 성공
- 환호 소리: 계약 성사
```

---

### 7단계: 타이밍 조정

#### 대사 속도
```
기본: 3-4초 (짧은 대사)
중간: 5-7초 (보통 대사)
긴 대사: 8-10초
```

#### 장면 전환
```
페이드 인/아웃: 0.3-0.5초
컷 전환: 즉시 (긴장감 있을 때)
```

#### 침묵 추가
```
감정적 순간: +1-2초 침묵
코미디 타이밍: +0.5초 침묵
```

---

### 8단계: 리뷰 및 수정

#### 체크리스트
- [ ] 모든 대사에 음성이 적용되었는가?
- [ ] 이미지와 대사가 일치하는가?
- [ ] 자막이 정확하게 표시되는가?
- [ ] BGM 볼륨이 적절한가?
- [ ] 장면 전환이 자연스러운가?
- [ ] 타이밍이 어색한 부분은 없는가?

#### 미리보기
```
1. 전체 재생
2. 문제 구간 메모
3. 수정
4. 다시 재생
```

---

### 9단계: 내보내기

#### 설정
```
형식: MP4
해상도: 1920x1080 (Full HD)
프레임: 30fps
비트레이트: 10-15 Mbps
```

#### 내보내기 과정
```
1. "내보내기" 클릭
2. 설정 확인
3. 저장 위치 선택
4. "시작" 클릭
5. 완료 대기 (30-60분 예상)
```

## 고급 팁

### Tip 1: 일관성 유지
```
- 같은 캐릭터 = 같은 음성 설정
- 같은 장소 = 유사한 배경
- 전체적으로 통일된 자막 스타일
```

### Tip 2: 감정 표현
```
1. 음성 피치 조절:
   - 화날 때: +2
   - 슬플 때: -2
   - 놀랄 때: +3, 속도 1.2x

2. 이미지 효과:
   - 당황: 땀방울 추가
   - 충격: 화면 흔들림 효과
   - 기쁨: 밝은 배경
```

### Tip 3: 코미디 타이밍
```
1. 펀치라인 전 0.3초 침묵
2. 반응샷 1-2초 유지
3. 과장된 표정 강조
```

### Tip 4: 렌더링 시간 절약
```
1. 저화질로 먼저 테스트
2. 확인 후 고화질로 최종 렌더링
3. 구간별로 나눠서 작업 가능
```

## 문제 해결

### 문제 1: 음성이 어색해요
```
해결:
- 속도 조절 (0.9x - 1.1x)
- 다른 음성 선택
- 문장 구분 조정 (쉼표, 마침표)
```

### 문제 2: 이미지가 흐릿해요
```
해결:
- 원본 이미지 해상도 확인 (최소 1920x1080)
- VREW 설정에서 "고품질" 선택
- 이미지 포맷 PNG 사용
```

### 문제 3: 타이밍이 안 맞아요
```
해결:
- 타임라인에서 수동 조정
- 대사 길이 확인
- 이미지 지속 시간 조정
```

### 문제 4: 용량이 너무 커요
```
해결:
- 비트레이트 낮추기 (8-10 Mbps)
- 불필요한 효과 제거
- 이미지 최적화
```
