### 2단계: 이미지 만들기 (2-3일)

#### 시작 방법
1. **`character-designs.md`** 열기
2. 각 캐릭터의 **AI 프롬프트** 복사
3. Midjourney/DALL-E에 붙여넣기
4. 생성된 이미지 저장

#### 빠른 팁
- 캐릭터부터 먼저! (박상무 → 제니 → 마이크...)
- 배경은 나중에
- 파일명: `character_name_expression.png`

---

### 3단계: VREW 작업 (1-2일)

#### 시작 방법
1. VREW 열기
2. **"새로 만들기"** → **"텍스트로 영상 만들기"**
3. `scenes/scene-01-script.txt` 복사 → 붙여넣기
4. 음성 설정 → 이미지 추가

#### 빠른 팁
- 한 장면씩 차근차근
- 자주 저장!
- `vrew-guide.md` 참고
