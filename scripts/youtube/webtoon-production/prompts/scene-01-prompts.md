## 추가 팁

### Midjourney 사용 시
1. `--ar 16:9` 필수 (가로 영상용)
2. `--v 6` 최신 버전
3. `--style raw` 추가 시 더 일관된 스타일
4. 같은 캐릭터 생성 시 `--seed` 값 고정

### DALL-E 사용 시
1. "webtoon style", "Korean manhwa" 키워드 필수
2. 상세한 묘사 중요
3. 감정 표현 명확히 기술
4. 배경 설명 포함

### Stable Diffusion 사용 시
1. 모델: Anything V5 또는 CounterfeitV3
2. LoRA: Korean Webtoon Style
3. Steps: 30-50
4. CFG Scale: 7-9
5. Negative prompt 중요
