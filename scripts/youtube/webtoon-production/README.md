### 제작 단계 (2-4일차)

## 📅 상세 제작 일정

### Day 1: 이미지 준비

#### 오전 (4시간)
1. **캐릭터 디자인 읽기** (30분)
   - `character-designs.md` 정독
   - 각 캐릭터 특징 숙지

2. **AI 이미지 생성** (3.5시간)
   - 박상무 기본 이미지 5개
   - 제니 기본 이미지 4개
   - 마이크 기본 이미지 3개
   - 수잔 기본 이미지 3개
   - 김인턴 기본 이미지 3개
   - 앤더슨 기본 이미지 2개

**사용 프롬프트**: `prompts/` 폴더 참조

#### 오후 (4시간)
3. **배경 이미지 생성** (2시간)
   - 회의실 (3개 앵글)
   - 사무실 (2개 앵글)
   - 개인 사무실 (2개)
   - 복도 (1개)
   - 식당 (1개)

4. **장면별 합성 이미지** (2시간)
   - 장면 1-5 합성 이미지 제작
   - Photoshop/Canva에서 캐릭터+배경 합성

**총 이미지**: 약 30개 완성

---

### Day 2: 이미지 완성 + VREW 시작

#### 오전 (4시간)
1. **장면별 합성 이미지 계속** (3시간)
   - 장면 6-17 합성 이미지 제작

2. **이미지 파일 정리** (1시간)
   ```
   /images/
   ├── characters/
   │   ├── park_basic.png
   │   ├── park_angry.png
   │   ├── jenny_basic.png
   │   └── ...
   ├── backgrounds/
   │   ├── meeting_room_01.png
   │   └── ...
   └── scenes/
       ├── scene_01.png
       ├── scene_02.png
       └── ...
   ```

#### 오후 (4시간)
3. **VREW 프로젝트 생성** (30분)
   - 새 프로젝트
   - 16:9 비율 설정

4. **장면 1-8 작업** (3.5시간)
   - 스크립트 입력
   - 음성 설정
   - 이미지 삽입
   - 자막 확인

---

### Day 3: VREW 작업 완료

#### 오전 (4시간)
1. **장면 9-17 작업** (4시간)
   - 스크립트 입력
   - 음성 설정
   - 이미지 삽입
   - 자막 확인

#### 오후 (4시간)
2. **BGM 추가** (1시간)
   - 1막: 경쾌한 음악
   - 2막: 긴장감 음악
   - 3막: 감동적 음악

3. **효과음 추가** (1시간)
   - 컴퓨터 오류음
   - 전화벨
   - 문 두드리기
   - 박수, 환호

4. **타이밍 조정** (2시간)
   - 대사 속도 확인
   - 장면 전환 조정
   - 침묵 추가

---

### Day 4: 최종 완성

#### 오전 (3시간)
1. **전체 리뷰** (1.5시간)
   - 처음부터 끝까지 시청
   - 문제점 메모

2. **수정 작업** (1.5시간)
   - 어색한 타이밍 조정
   - 음성 재설정 (필요시)
   - 자막 오타 수정

#### 오후 (3시간)
3. **최종 확인** (1시간)
   - 다시 한 번 전체 시청
   - 체크리스트 확인

4. **렌더링** (2시간)
   - 1920x1080, 30fps
   - MP4 형식
   - 고품질 설정

## 📝 스크립트 사용법

### 스크립트 파일 구조
```
scenes/scene-01-script.txt:

[박상무]
(거만한 어조로)
여러분, 여러분. 내가 이 업계에서 일한 지가 30년이야.

[제니]
(도움이 되려고)
상무님, 금요일 고객 프레젠테이션 건인데요...
```

### VREW에 입력하는 방법
1. 스크립트 파일 열기
2. 전체 복사
3. VREW에 붙여넣기
4. 화자 자동 인식
5. 음성 설정

## 🆘 문제 해결

### 자주 묻는 질문

**Q: 이미지를 몇 개나 만들어야 하나요?**
A: 최소 50개, 권장 70개. 각 장면당 평균 3-4개.

**Q: VREW 무료 버전으로 가능한가요?**
A: 가능하지만 워터마크가 표시됩니다. 제거하려면 Pro 버전 필요.

**Q: Midjourney 대신 무료 도구는?**
A: Stable Diffusion, Bing Image Creator, Canva 무료 버전.

**Q: 제작 시간이 얼마나 걸리나요?**
A: 처음이라면 4-5일. 경험 있으면 2-3일.

**Q: 음성이 어색하면?**
A: 속도 조절 (0.9x-1.1x), 다른 음성 선택, 문장 구분 조정.

## 🎬 최종 팁

### 성공을 위한 5가지 팁

1. **일관성이 핵심**
   - 같은 캐릭터는 같은 스타일
   - 음성 설정 일관되게

2. **타이밍이 중요**
   - 대사와 이미지 싱크
   - 적절한 침묵 활용

3. **감정 표현 강조**
   - 표정 변화 명확하게
   - 음성 피치로 감정 표현

4. **BGM 볼륨 주의**
   - 대사보다 낮게 (20-30%)
   - 감정에 맞는 음악 선택

5. **처음부터 완벽하지 않아도 됨**
   - 첫 작품은 연습
   - 피드백 받고 개선
